## 恢复操作约束

关联备份需要分别管理平台状态、Connector 身份与根密钥、认证日志及数据库目标回执；单一平台 dump 不等于完整灾备。活动 bbolt 必须使用一致性快照或停写后的副本，不能直接复制活动文件并宣称完整恢复。包密钥按原保留策略独立管理，不能通过恢复旧日志复活已删除密钥。

恢复时保持 API 和执行入口关闭：先验证备份完整性及目标身份；再通过既有本机管理员重设用例生成新凭据并清除旧会话，清空快照中的数据源绑定，重新核对并批准当前绑定。旧快照中的密码、绑定、预览、API 世代及许可都不能直接充当当前授权。最后以新世代只读核对原回执，未知、冲突或孤儿回执保持冻结。测试包含快照后的密码轮换和绑定撤销，恢复后必须拒绝旧密码且不恢复已撤销绑定。

复用 MySQL 官方工具、Better Auth 现有密码恢复用例、当前签名/领域/存储适配器和既有测试框架，没有引入新的产品依赖。参数以本机 26.7 工具帮助核实，不据此承诺 MySQL 8.0。发布用安装包、自动灾备调度、跨机密钥迁移及正式运维工具仍属于后续发布阶段的交付范围，不能把本轮测试辅助工具当成产品备份服务。
