# Shuriva UI v0.2 设计基线

> 状态：现状记录，已冻结为审查基线。本文只描述 UI v0.2 的原貌与既定约束，不包含改造实施。
>
> 基线版本：UI v0.2（`preview/` 交互原型）
>
> 审查日期：2026-11-09
>
> 适用范围：7 个原型页面、共享 CSS、共享交互脚本、原型内的 Mock 状态与响应式行为。

---

## 1. 基线范围与证据

### 1.1 页面清单

| 文件 | `data-page` | 页面标题 | 主要任务 |
| --- | --- | --- | --- |
| `preview/home.html` | `home` | 首页 | 描述需求创建并进入工作台 |
| `preview/workspaces.html` | `workspaces` | 我的工作台 | 查找、重命名、复制、删除工作台 |
| `preview/workspace.html` | `workspace` | 客户业务总览 | 日常查询、筛选、详情、多源状态 |
| `preview/editor.html` | `editor` | AI 编辑器 | 对话修改、配置绑定、实时预览、保存 |
| `preview/datasources.html` | `datasources` | 数据源 | 连接管理、状态、使用情况、添加向导 |
| `preview/permissions.html` | `permissions` | 团队权限设计 | 角色、字段、记录范围、导出与 AI 授权预览 |
| `preview/settings.html` | `settings` | 设置与演示 | 产品模式、架构边界、故障模拟、重置演示 |

### 1.2 证据来源

- 直接读取 7 个 HTML 文件的 CSS、JS 和页面结构。
- 在桌面端 `1440 × 1000`、移动端 `390 × 844` 逐页截图检查。
- 检查弹窗、抽屉、数据源向导、团队权限视图和角色预览。
- 用 DOM 检查键盘焦点、弹窗关闭后的焦点位置、表格行交互。
- 用 WCAG 对比度公式计算关键文字、图标、边框和图表颜色。
- 使用 `ui-ux-pro-max` 的 UX 与设计系统检索结果作为审查标尺；其推荐的蓝色 / Fira 方案与既定青绿色 / 现有字体体系冲突，未采用为替代方案。
- 参考 `shuriva-ui-guidelines`、`shuriva-data-security`、`shuriva-product-context` 的项目约束。

### 1.3 原型性质

这是 **纯前端交互原型**：

- 页面由共享 JavaScript 在浏览器中渲染，不是 React 页面。
- 数据、AI 响应、连接测试、权限结果全部为本地 Mock。
- 状态保存在 `localStorage` 的 `stackoryn-design-v02` 键中。
- 没有真实数据库、真实模型、真实鉴权或跨设备同步。
- 原型中大量使用 "模拟 / Mock / 仅预览 / 不是生产鉴权" 标识，这属于基线的一部分，后续不得删除或弱化。

## 2. 全局界面框架

### 2.1 应用外壳

```text
.app-shell
├── .sidebar                 固定左侧栏，220px
│   ├── 品牌
│   ├── 工作空间切换
│   ├── 创建工作台
│   ├── 主导航
│   ├── 最近使用
│   ├── 部署说明
│   └── 演示账号
└── .app-main
    ├── .global-bar          顶部栏，56px
    ├── .role-preview-bar    团队版角色预览条（仅工作台 / 编辑器）
    ├── page                 页面主体
    └── .app-bottom-note     全局 Mock 说明
```

- 左边栏固定定位，主区域使用 `margin-left: 220px` 抵消。
- 顶部栏包含面包屑、Mock 徽标、演示设置入口和演示头像。
- 编辑器路由下，左边栏收窄为 72px；移动端编辑器隐藏文字，仅保留图标。
- 页面主体基础内边距为 `30px 32px 32px`。
- 背景 `#F8FAFB`，卡片白色，卡片边框 `#E3E9ED`，圆角 10px。
- 全局底部说明："交互设计预览 · 全部使用虚构数据 · 不连接真实数据库"。

### 2.2 导航结构

主导航：

- 首页
- 我的工作台（工作台和编辑器路由都保持选中）
- 数据源
- 成员与数据权限（仅团队版显示）
- 设置与演示（左侧栏底部）

最近使用最多显示 4 个工作台；当前工作台在最近使用中高亮。

### 2.3 版本与角色

| 概念 | 原型表现 |
| --- | --- |
| Community | 单用户、个人工作空间、后端直连数据库、无额外 Connector、多数据源 |
| Team | 可切换的团队版设计预览；导航增加权限入口；工作台增加角色预览条 |
| 数据管理员 | 可编辑工作台，查看完整字段 |
| 客服 | 手机号脱敏、成本隐藏、仅本人负责记录 |
| 财务 | 手机号 / 邮箱脱敏、可查看成本、可导出 |
| 门店运营 | 手机号脱敏、仅所属门店记录、不可导出 |

切换角色只改变前端 Mock 可见结果，不改变登录身份，也不构成真实鉴权。

## 3. 页面结构基线

### 3.1 首页 / Home

**布局**

- 最大内容宽度 1480px，顶部留白 41px。
- 自定义页头：英文 eyebrow `YOUR BUSINESS, CONNECTED` + H1 + 版本徽标。
- 创建区：大输入框、数据源选择按钮、创建按钮。
- 建议任务：3 个模板按钮。
- "继续你的工作"：3 张工作台卡片。
- "数据已就位"：最多 4 个数据源横向列表。

**交互**

- 输入需求后可创建草稿并进入编辑器。
- 可选择多个数据源参与创建；显示数量与数据库类型图标。
- 模板按钮填充并创建对应类型的草稿。
- 工作台卡片和最近使用可进入工作台。
- 数据源条目可打开详情抽屉。

**视觉**

- 顶部创建区使用细边框和很浅的阴影，是全局最突出的输入区域。
- 卡片 hover 上移 2px，边框变青绿色。
- 首页 H1 为 28px，是全局最大标题。

### 3.2 工作台目录 / Workspaces

**布局**

- 标准页头：`WORKSPACES` + H1 + 描述 + 创建按钮。
- 工具栏：搜索、数据源筛选、结果数量。
- 目录表面板：表头 + 行式布局，列为工作台、数据源、修改时间、操作。
- 行内包含图标、标题、描述、数据源短标签、3 个图标操作。
- 底部脚注说明删除和复制不会改变数据库记录或权限。

**交互**

- 搜索按标题过滤；筛选按数据源过滤。
- 整行名称按钮进入工作台。
- 重命名、复制、删除使用图标按钮；删除走确认弹窗。
- 空结果使用空状态，但不提供清除筛选按钮。

**视觉**

- 采用"目录"而非卡片网格，信息密度高于首页卡片。
- 表头 10px、次要文字 9–10px、源短标签 9px。
- 行高约 72px，桌面端操作区常显。

### 3.3 业务工作台 / Workspace

**布局**

1. 页头：工作台标题、已保存徽标、描述、刷新按钮、用 AI 修改按钮。
2. 元信息行：数据源胶囊、只读标识、版本号、数据说明按钮。
3. 联动筛选条：客户选择、映射说明、查看绑定。
4. 指标条：三列（匹配订单、实付金额、待核查订单）。
5. 主列：订单模块（工具栏、表格、分页、来源页脚）。
6. 主列下方：产品使用趋势（客户总览类型时显示）。
7. 右列：客户资料、记录范围提示。

**交互**

- 客户联动筛选同时影响订单与活动模块，不执行跨库 JOIN。
- 订单表格支持搜索、时间、渠道、排序、分页，每页固定 6 条。
- 行可点击或按 Enter 打开订单详情抽屉；没有 Space 键支持。
- 来源按钮打开模块来源说明；数据说明打开 SQL / 权限说明抽屉。
- 刷新只触发 toast，不改变实际数据；无模块级忙碌状态。
- 单个数据源离线时，仅对应模块显示失败空状态，其余模块继续可用。
- 团队版顶部角色预览条可切换客服 / 财务 / 门店运营视角。

**视觉**

- 指标数字 27px，标签 10–11px，说明 10px。
- 表格 11px，表头 10px，次要文字 9px。
- 右列固定 258px，宽屏 290px，1250px 以下 225px。
- 图表柱 8–12 根，主色 `#81B4A8`，每 3 根使用更浅的 `#B4D3CA`。
- 图表没有数值轴、图例或可展开的数据表。

### 3.4 AI 编辑器 / Editor

**布局**

- 编辑器工具栏：返回、标题、草稿状态徽标、基于版本、放弃修改、保存。
- 桌面端双栏：左 320px 编辑面板，右侧实时预览。
- 左栏两个标签：AI 修改、数据与模块。
- AI 修改：消息列表、变更清单、生成进度、停止按钮、快捷指令、输入框。
- 数据与模块：工作台数据源、模块绑定、客户标识映射、显示配置开关。
- 右侧：预览栏 + 与正式工作台相同的渲染器。
- 980px 以下左栏变 270px；700px 以下变为"对话与配置 / 工作台预览"两个移动标签。

**交互**

- AI 为关键词匹配的 Mock，延迟 1100ms，可停止。
- AI 响应明确标注"模拟响应"；变更清单列出模拟改动。
- 保存前所有显示模块必须绑定兼容来源；不满足时切到数据标签并 toast。
- 放弃修改走确认；离开未保存草稿会确认并把草稿留在本地。
- `Ctrl/Cmd + Enter` 发送，避免中文输入法 Enter 误发。
- 生成中保存禁用；预览与正式工作台使用同一渲染函数。

**视觉**

- 编辑面板与预览区均为白色，预览区背景略灰。
- 面板内大量 9–10px 辅助文字。
- 预览区会压缩指标、表格、右栏和图表，形成"画中画"密度。

### 3.5 数据源 / Datasources

**布局**

- 标准页头 + 添加数据源按钮。
- 连接模式说明条：Community 显示"应用后端直连"；Team 显示"连接方式待定"。
- 统计行：数据源数、可用数、离线数、数据库类型数。
- 工具栏：搜索 + 引擎分段筛选。
- 数据源列表：数据源、环境与访问、连接状态、使用情况、操作。
- 底部三栏说明：连接独立、模块来源明确、密码不在浏览器保存。

**交互**

- 搜索名称 / 数据库名；分段筛选引擎。
- 点击数据源打开详情抽屉，含概览、Schema、绑定、使用情况。
- 管理 / 编辑打开详情或向导。
- 添加数据源为三步向导：选择类型 → 连接配置 → 访问范围。
- 第二步可测试连接、模拟失败；成功后进入第三步。
- 向导任何字段变更都会清空测试结果；下一步因此禁用。
- 详情抽屉可查看 SQL 示例，但不能直接复制。

**视觉**

- 数据源图标使用引擎字母与品牌色（PostgreSQL 蓝、MySQL 黄、ClickHouse 黄）。
- 状态使用圆点 + 文案徽标；部分其他位置仅圆点。
- 列表行高约 78px，移动端折叠表头，改为两列卡片式行。

### 3.6 团队权限 / Permissions

**Community 状态**

- 独立介绍卡片，说明开源版单用户，团队权限为独立预览。
- 按钮进入团队权限视图，仅切换原型状态。

**Team 状态**

- 页头 + 预览成员视角 + 保存策略。
- 左侧角色卡：客服、财务、门店运营。
- 右侧策略面板：字段与记录 / 数据源与操作 / 关联成员。
- 字段权限：原文可见、脱敏可见、不可访问；示例结果同步变化。
- 记录范围：全部授权记录、本人负责、所属门店；显示规则示例。
- 数据源：允许来源复选框、导出开关、敏感字段交给 AI 开关。
- 关联成员：模拟成员与身份说明。
- 顶部与底部明确"不是生产鉴权 / 前端不是安全边界"。

**视觉**

- 权限页使用紫色角色预览条与青绿色主色并存。
- 表格为 11px，策略说明 9–10px。
- 移动端角色卡改为整行列表，策略表压缩到 8–10px。

### 3.7 设置与演示 / Settings

**布局**

- 两列设置卡片网格，1400px 最大宽度。
- 产品模式：Community / Team 两个可点击选项，立即生效。
- 架构路径：浏览器 → 你的后端 → 多个数据库。
- 局部失败演示：逐个数据源模拟断开 / 恢复。
- 本地演示数据：存储说明、Mock 边界、重置按钮。

**交互**

- 切换版本会即时改变导航、首页徽标和工作台权限入口。
- 断开数据源会即时影响工作台模块状态。
- 重置演示数据走确认。
- 所有说明明确当前无真实连接、无跨设备同步。

**视觉**

- 卡片 23px 内边距，2×2 布局，980px 以下单列。
- 架构图使用 3 个等宽节点、箭头和高亮后端节点。

## 4. 设计 Token 提取

### 4.1 颜色

**根级 CSS 变量**

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#F8FAFB` | 页面背景 |
| `--surface` | `#FFFFFF` | 卡片 / 输入背景 |
| `--sidebar` | `#F4F7F8` | 左侧栏 |
| `--text` | `#233641` | 主文字 |
| `--muted` | `#7C8D9C` | 次要文字 |
| `--sub` | `#556976` | 次级文字 / 按钮文字 |
| `--border` | `#E3E9ED` | 卡片、分隔线 |
| `--primary` | `#0F766E` | 青绿色主色 |
| `--primary-soft` | `#E7F2EF` | 主色浅背景 |
| `--danger` | `#B74949` | 危险 |
| `--orange` | `#A56A19` | 警告 / 成本 |
| `--purple` | `#8160B1` | 状态不一致 / 权限预览 |
| `--blue` | `#4177A3` | 生产环境 / 信息 |

**实际使用特征**

- 共享 CSS 中出现 **280 个唯一十六进制颜色**，其中 **259 个只出现一次**。
- 仅检测到 **85 处 `var()` 引用**。
- 大量颜色直接写死在组件规则中，根变量只覆盖一小部分语义。
- 颜色族以青绿、灰蓝、暖黄、紫、红为主，没有渐变或发光装饰。

### 4.2 字体

**字体栈**

```css
Inter, -apple-system, BlinkMacSystemFont, "Segoe UI",
"PingFang SC", "Microsoft YaHei", sans-serif
```

- 原型声明 Inter，但没有 `@font-face` 或 webfont 引用；实际渲染取决于本机是否安装 Inter，否则回落到系统字体。
- 等宽字体：`ui-monospace, SFMono-Regular, Consolas, monospace`。
- 根字号 13px，行高 1.55。
- 中文与数字混排；金额使用 `font-variant-numeric: tabular-nums`。

**字号分布（`font-size` 声明次数）**

| 字号 | 次数 | 主要用途 |
| --- | --- | --- |
| 8px | 24 | 徽标、图表标签、脚注、移动端说明 |
| 9px | 54 | 次要说明、表头辅助、卡片元信息 |
| 10px | 85 | 表格辅助、徽标、元信息、按钮 |
| 11px | 51 | 表格正文、表单标签、导航 |
| 12px | 40 | 按钮、正文、输入 |
| 13px | 11 | 卡片标题、局部正文 |
| 14px | 10 | 页面标题、卡片标题 |
| 15–28px | — | 分区标题、指标数字、页面 H1 |

标题层级：H1 25px（首页 28px），H2 16–17px，H3 14px，卡片标题 13–14px。

### 4.3 间距

- 页面内边距：30px / 32px；1250px 以下 26px / 24px；980px 以下 24px / 20px；700px 以下 23px / 16px。
- 常用间距：3、5、6、7、8、9、10、11、12、13、15、16、17、18、20、21、22、23、24、25、27、28、29、30、32、33、34、35px。
- 缺少统一的 4px / 8px 间距尺度；很多值是按局部视觉临时调整。

### 4.4 圆角

| 圆角 | 用途 |
| --- | --- |
| 3–4px | 徽标、小图标、支付图标 |
| 5–6px | 输入、标签、导航项、搜索框 |
| 7–8px | 按钮、卡片、数据源行、提示条 |
| 9–10px | 指标条、主卡片、对话气泡 |
| 11–13px | 首页创建区、弹窗、抽屉 |

圆角范围 3–13px，缺少统一层级。

### 4.5 边框与阴影

- 卡片和输入边框主要为 1px `#E3E9ED` / `#DFE7EC`。
- 聚焦边框为 `#8DB8AC`，聚焦轮廓为 2px `#15958A`、偏移 3px。
- 阴影非常克制：
  - 首页创建区：`0 3px 10px #163E3510`。
  - 工作台卡片 hover：仅边框和位移。
  - 弹窗：`0 20px 90px #172C3B35`。
  - Toast：`0 5px 25px #173C2515`。
- 没有渐变、霓虹、玻璃拟态或装饰性光晕。

### 4.6 布局尺寸

| 项目 | 值 |
| --- | --- |
| 左侧栏 | 220px；编辑器 72px；980px 以下 190px；编辑 60px；700px 以下抽屉式 220px |
| 顶部栏 | 56px；移动端 52px |
| 页面最大宽度 | 首页 1480px；设置 1400px；≥1750px 时 `.page` 1510px |
| 工作台主 / 右列 | 1fr + 258px；宽屏 290px；1250px 225px；980px 以下单列 |
| 编辑器分栏 | 320px + 1fr；1250px 290px；980px 270px；700px 以下单栏切换 |
| 弹窗 | 560px；宽 690px；抽屉 485px |
| 表格每页 | 固定 6 条 |
| 移动端表格 | `min-width: 760px` + 横向滚动 |

### 4.7 动效

- 按钮、卡片、边框过渡 0.14–0.18s。
- Toast 入场 0.18s。
- 生成中 spinner 0.8s 线性旋转。
- 支持 `prefers-reduced-motion: reduce`，全部动画和过渡关闭。
- 没有页面级转场、骨架屏或滚动动画。

## 5. 组件清单与基线行为

## 6. 跨页面一致性评估

### 6.1 已经一致的部分

- 外壳、侧栏、顶部栏、面包屑在各页完全一致。
- 卡片表面、边框、圆角和页面背景一致。
- 按钮、徽标、空状态、提示条、Toast 的视觉语言一致。
- 数据源在所有页使用同一套图标与状态语言。
- Mock 标识、只读标识、安全边界说明在各页保持同一口径。
- 多数据源工作台使用同一渲染器，正式页与编辑器预览共享结构。
- 响应式断点统一为 1750 / 1250 / 980 / 700px。
- 减少动效偏好被统一尊重。

### 6.2 存在漂移的部分

| 维度 | 表现 |
| --- | --- |
| 页面宽度 | 首页 1480px、设置 1400px、宽屏 `.page` 1510px |
| 页头 | 首页完全自定义；其他页使用 pageHead；编辑器没有页面级 H1 |
| 英文 eyebrow | 有的页面有、有的没有；`WORKSPACES` / `DATA SOURCES` / `SETTINGS` 与中文标题混排 |
| 字号 | 8–28px 共十余级；同类信息在不同页面使用 9/10/11px 不等 |
| 颜色 | 280 个唯一 hex；同类灰色有多个近似值 |
| 圆角 | 3–13px 共多级；按钮 7px、输入 6px、卡片 8–10px、弹窗 13px |
| 间距 | 1–35px 大量一次性值；页面内边距有 30/32、26/24、24/20、23/16 四套 |
| 状态表达 | 数据源列表有圆点 + 文案，首页和来源胶囊只有圆点 |
| 筛选控件 | 有的有可见标签，有的只有占位符或上下文 |
| 禁用原因 | 有的只用 `title`，有的没有说明 |
| 图表 | 只有工作台和编辑器预览使用；样式与可访问性未形成组件规范 |

### 6.3 页面密度基线

- 首页：低密度、引导型。
- 目录 / 数据源：中等密度。
- 工作台：高密度，表格是主体。
- 编辑器：左配置 + 右预览，双高密度。
- 权限：高密度配置表。
- 设置：中低密度说明卡片。

> 基线结论：v0.2 已有清晰的"克制青绿色 + 数据优先 + 高信息密度"方向，不需要推翻。主要问题是字号、对比度、状态语义和 Token 收敛，而不是整体视觉语言。

## 7. 响应式基线

| 断点 | 主要变化 |
| --- | --- |
| ≥1750px | 页面最大 1510px；工作台右列 290px；表格行更高 |
| ≤1250px | 页内边距缩小；表格工具栏换行；工作台右列 225px；编辑器 290px；首页数据源 2 列；设置单列 |
| ≤980px | 侧栏 190px；工作台变单列；工作台目录隐藏修改时间；数据源列表隐藏环境与使用情况；权限布局单列；编辑器 270px；编辑器预览指标改为 2 列并隐藏第三项 |
| ≤700px | 侧栏变抽屉；顶部栏 52px；页面 16px 内边距；指标 2 列并隐藏第三项；表格最小 760px 横向滚动；编辑器变"对话 / 预览"标签；权限表、设置卡、数据源行全部压缩；Toast 全宽 |
| 减少动效 | 所有 animation / transition / smooth scroll 关闭 |

**移动端已知基线行为**

- 工作台指标条：`grid-template-columns: repeat(2, 1fr)`，最后一个指标 `display: none`。
- 编辑器预览指标：980px 以下就隐藏第三项。
- 数据目录：隐藏表头和修改时间；操作按钮纵向排列。
- 数据源：隐藏表头、环境与使用情况；保留状态和操作。
- 权限：策略表 8–10px；规则代码换行。
- 表格：保留全部列，但需要横向滚动，最小宽度 760px。

## 8. 可访问性基线

### 8.1 已经具备

- 全局 `:focus-visible` 2px 青绿色轮廓，偏移 3px。
- 原生 `<dialog>` + `aria-labelledby`。
- Toast 容器 `aria-live="polite"`。
- 表格行有 `aria-label`；多数图标按钮有 `aria-label`。
- 表单字段使用 `<label class="field">` 包裹。
- 中文输入法安全的 `Ctrl/Cmd + Enter` 发送。
- 支持减少动效。
- 危险操作有确认弹窗。
- CSV 导出按字段权限脱敏，并做 CSV 注入防护。
- 大量 Mock / 权限边界文字，避免把演示误认为真实能力。

### 8.2 基线缺口

- 次要文字、表头、占位符、徽标、图表颜色对比度不足。
- 搜索、筛选、下拉缺少可访问名称。
- 导航、标签页、分段筛选、步骤条缺少 ARIA 状态。
- 表格行 `role="button"` 破坏表格语义；键盘只支持 Enter。
- 弹窗关闭后焦点不能可靠返回触发元素。
- 移动端大量触控目标小于 44×44px。
- 表单错误只有顶部摘要，没有字段级关联。
- 图表只有 hover title，没有键盘可读数据。
- 多个状态只靠颜色圆点表达。
- 页面标题层级不统一，编辑器没有 H1。
- 移动端侧栏抽屉没有焦点约束。

## 9. 基线约束（后续不得随意改变）

1. **保留青绿色主色** `#0F766E`，除非有明确、经过确认的品牌理由。
2. **保留现有字体体系**，不擅自更换字体家族；字体加载方式需要单独决策。
3. **保留现有页面结构与信息架构**：外壳、侧栏、工作台双栏、编辑器双栏、三步数据源向导、权限三标签。
4. **保留高信息密度和数据优先**，不改成营销页或低密度卡片堆叠。
5. **保留"克制、专业、无渐变 / 无发光"的视觉语言**。
6. **不引入第二套 UI 组件库**；继续使用 shadcn/ui + Base UI。
7. **保留 Community 与 Cloud 的边界表达**：Community 单用户、自部署后端直连、多数据源、默认只读；Cloud 连接方案仍未确定。
8. **保留 Mock 与真实能力的区分**，不得把模拟连接、模拟 AI、模拟权限描述为真实功能。
9. **保留多数据源独立执行、独立失败、显式绑定**的表达。
10. **保留 AI 只生成受控配置、不执行任意 HTML / JS / SQL** 的产品约束。

## 10. 当前 React 实现差距（不在本次修改范围）

`src/` 目前仍是 Vite + React 脚手架：

- `src/App.tsx` 是 React / Vite 欢迎页，不是 UI v0.2 页面。
- `src/index.css` 使用默认 shadcn 灰阶 token（`--primary` 接近黑色）和 Geist 字体。
- v0.2 的 `.surface` / `.btn` / `.badge` / `.business-table` 等类尚未迁移为 React + Tailwind 组件。
- 原型使用青绿色 + Inter 声明；React 脚手架使用 Geist + 灰阶。

这意味着：**设计基线在 `preview/`，实现基座在 `src/`，两者尚未对齐。** 在进入页面优化前，必须先确认字体与 Token 的单一来源，避免同时维护两套视觉系统。

## 11. 基线结论

UI v0.2 的产品方向、页面结构和视觉语言已经成立：

- 青绿色主色克制，符合数据工作台气质。
- 工作台是主体，AI 是创建 / 修改工具，这一点在结构中表达清楚。
- 多数据源、独立失败、权限预览、Mock 边界都有明确 UI 表达。
- 高信息密度表格与双栏编辑器是应该保留的核心资产。
